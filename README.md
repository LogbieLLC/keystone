# keystone

Offline X.509 certificate-authority key and certificate generator for an air-gapped Ubuntu laptop.

## Project status

- **No release is ready for use with a real CA yet.** Every release is a `-dev` release until the PRD's version 1 acceptance (milestone M8) is complete.
- Keystone has one maintainer. If the maintainer is unavailable for a long time, the project pauses.
